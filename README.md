# SmartTaskManager iOS

AI-assisted mobile application development demo project showcasing how engineering teams can leverage AI throughout the Software Development Lifecycle (SDLC).

## Tech Stack

- Swift
- UIKit
- MVVM Architecture
- URLSession
- UserDefaults
- OpenAI API Integration
- XCTest

## AI Engineering Workflow

- Jira for project management
- Confluence for architecture and documentation
- Cursor for AI-assisted development
- Atlassian MCP for Jira + Confluence integration
- GitHub for version control

## Smart Features

- AI Task Priority Suggestion
- AI Task Breakdown into Subtasks
